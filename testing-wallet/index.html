The reference web wallet for SMART Health Check-in.

Waiting for a check-in request from the page that opened this wallet…

This is the reference web wallet for the SMART Health Check-in connectathon. It answers check-in requests from a Verifier page that opens it.

To test how your Verifier handles bad or large responses, set options in the testing panel below, choose "Copy wallet URL for these settings", and add that URL as a wallet on your page. Every check-in sent to that URL gets those options. The URL format is this wallet's own, not part of SMART Health Check-in.

To try it, open the testing EHR or the reference clinic check-in page, and choose this wallet.
